
# Crop Recommendation System

## Project Overview
This project recommends a crop based on soil nutrients
and environmental conditions using a Decision Tree model.
MongoDB stores the dataset, model evaluation details,
and prediction history.

## Technologies Used
- Python
- MongoDB
- PyMongo
- Pandas
- Scikit-learn
- Joblib

## Dataset
The dataset contains soil and weather features:
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall

The target column is `label`, which represents the crop.

## Machine Learning
- Algorithm: Decision Tree Classifier
- Training split: 70%
- Testing split: 30%
- Random state: 42
- Evaluation: Accuracy, precision, recall, F1-score,
  and confusion matrix

Actual evaluation results are generated by the training script.


## Model Evaluation Results

- Algorithm: Decision Tree Classifier
- Dataset size: 2,200 rows
- Training samples: 1,540
- Testing samples: 660
- Train/test split: 70/30
- Random state: 42
- Test accuracy: 97.88%
- Macro-average precision: approximately 0.98
- Macro-average recall: approximately 0.98
- Macro-average F1-score: approximately 0.98

The model was evaluated on a held-out test set.
These results apply to the selected dataset and split
and do not guarantee the same accuracy in real-world
agricultural conditions.


## MongoDB Collections
- `crop_samples`: dataset records
- `model_runs`: model evaluation summaries
- `predictions`: prediction history

## How to Run

Activate the virtual environment:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
python -m pip install pandas pymongo scikit-learn joblib
```

Import dataset:

```bash
python scripts/import_data.py
```

Train the model:

```bash
python scripts/train_model.py
```

Run a prediction:

```bash
python scripts/predict_crop.py
```

Run MongoDB practice:

```bash
python scripts/mongodb_practice.py
python scripts/aggregation.py
python scripts/create_indexes.py
python scripts/add_validation.py
```

## Limitations
Predictions depend on the quality and coverage of the
training dataset. Recommendations should not be treated
as a substitute for local agricultural expertise.

## How to Run Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Ensure MongoDB is running locally.
5. Import the dataset and train the model using the scripts in `scripts/`.
6. Start the application using `streamlit run app.py`.
